# Revue responsive — Dahira Manager

## Contexte de vérification

Le tableau de bord a été revu sur un écran téléphone de 390 × 844 pixels et sur un écran bureau de 1 440 × 1 024 pixels. Les captures ont confirmé que l’interface reste lisible dans les deux contextes principaux d’utilisation.

## Ajustements appliqués

Sur téléphone, la navigation principale est déplacée dans une barre inférieure et les écrans secondaires sont accessibles depuis le panneau « Plus ». Les indicateurs passent sur une seule colonne afin de conserver une largeur de lecture confortable. Les boutons de pointage, de notification et de préparation du Goudi Adjouma sont dimensionnés pour une utilisation tactile.

Sur bureau, une navigation latérale persistante est affichée et le tableau de bord se réorganise en grilles de deux à quatre colonnes. Les tableaux disposent d’un défilement horizontal lorsqu’ils dépassent la largeur disponible, ce qui évite de masquer les colonnes importantes.

Les formulaires de compte, d’ajout de membre et les fiches individuelles utilisent des panneaux modaux qui restent utilisables sur petits écrans. Les dialogues à contenu long disposent d’un défilement vertical interne.

## Résultat

Le contraste texte/fond, les boutons, les cartes et les informations de pointage sont lisibles sur les deux formats. Le pointage reste explicitement présenté comme facultatif et la disponibilité du créneau de jeudi est visible sans nécessiter d’action supplémentaire.
